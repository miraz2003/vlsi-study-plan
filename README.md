# VLSI study plan

Masters and PhD options in VLSI, embedded systems and robotics for a CSE graduate, across France, Australia, USA, Italy, Germany, Canada, Ireland, New Zealand and the UK.

- `index.html` – filterable website (open it in a browser; it reads `data.json`)
- `data.json` – programs, professors, deadlines, cities and country rules
- `VLSI_All_in_One.xlsx` – everything in one Excel workbook

All facts come from official university and government pages; each entry links to its source.
